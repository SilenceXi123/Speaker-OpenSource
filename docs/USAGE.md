# 使用说明

## 字幕与扒词

先创建或选择项目，再上传音频。“生成字幕”用于字幕制作，“生成扒词”用于给编导或客户划稿。

云端识别走自建后端与阿里云模型，可提供说话人人数和词表提示；多人混音仍需人工复核分人结果。支持的本机模式先检测系统能力，再使用 Apple 识别。Apple 模式不提供混合多人音轨的自动说话人分离：独立人声轨可填写人物姓名，但多轨自动合板/时间线回传不在当前版本范围内。

台本可上传 TXT、MD、SRT、DOCX、PDF，用于核对人物、术语与措辞。只有显式开启歌词校对，且与语音可靠对齐的片段，才允许替换歌词。不要把整份台本当作无条件覆盖转写的答案。

识别后可以试听定位、批量改名、逐句修正说话人和文字，并主动清理语气词。质检与 DeepSeek 校对只能帮助发现问题，仍需对关键人名、专有词和时轴做抽检。

## Premiere 交付

按人物姓名上传同名 PNG 人名条，检查缺失项，然后下载 XML、SRT 或工程包。XML 用于 Premiere 图形文字字幕交付；保持音频、图片和 XML 引用路径有效。扒词可导出 TXT、SRT、DOCX。

现有能力通过文件交付，不会自动追踪 Premiere 内的删减、调序或人工校字。剪辑时间线再次变化后，不能假定旧字幕自动匹配新时间线。

## 长音频

当前 Fun-ASR 录音文件接口的总体上限与开启说话人分离时的建议时长不同：官方资料列出总体 12 小时/2GB，开启说话人分离建议不超过 2 小时，超长可能失败或超时。以自己的账号、模型和[官方文档](https://help.aliyun.com/zh/model-studio/fun-asr-recorded-speech-recognition-http-api)为准（核对日期：2026-11-04）。

CLI 的 `--auto-split` 会在本机用 FFmpeg 检测静音、按不超过 2 小时切分并保留边界重叠，再提交并合并回同一原始时间轴；静音文件会跳过。它需要可用的后端、FFmpeg 和足够的临时空间，不能只看到局部上传进度就认为任务完成。

## 声音复刻

1. 进入“声音复刻”，上传本次清晰的单人参考音频。
2. 选择 Next（默认推荐）或 CosyVoice 3.5 Flash；可用性取决于后端配置、地域、业务空间和账号授权。
3. 输入文案和语气提示，生成多个版本，逐个试听对比。
4. 选择满意版本下载。**实际写入本机文件成功后**，后端清理同项目、同参考音频关联的全部生成版本、参考音频和临时音色；Flash 的云端音色也进入删除流程。

试听、取消保存或写入失败不会触发该清理。用户下载一个版本即代表本次其余版本可丢弃；需要多份时应先按实际交付需求保存。未下载数据由 72 小时到期清理兜底；后台维护需要后端持续运行，云端删除失败可进入重试队列，不能把发出清理请求等同于即时释放厂商配额。

每次新的复刻流程重新上传参考，不把声音库作为永久归档。说话人识别用的声纹样本是另一项能力，不属于这次复刻参考清理范围。

## 离线模式

客户端通过后端健康探测判断可达性；系统认为没有互联网时，仍会检查局域网后端。真正不可达时展示离线提示，保留本机项目、识别、编辑与导出能力（取决于本机识别是否可用）。

离线时不会进行 DeepSeek 云端校对、云端声音复刻或服务器任务操作。恢复联网后可选择同步本机结果到服务器继续校对；不会把未进行的云端校对标为已完成。Apple 识别资源首次准备可能仍需要联网。

## 数据与部署边界

- 后端数据库及媒体默认保存在 `backend/data/`；部署和备份时保留该目录及自己创建的 `.env`。
- 云端识别/复刻会将相应音频交给配置的云服务；Apple 本机识别的音频处理发生在设备上，后续主动同步服务器是另一项数据流。
- 项目归属过滤不等于完整的账号权限隔离。当前普通任务/项目接口依赖可信环境，不建议直接面向公网或不可信租户开放。
- 使用团队后端时，由管理员设置受控网络、入口认证、HTTPS 与数据保留策略。公开项目不附带可共享的生产后端或云服务凭据。
- 用户素材、声纹/音色及第三方模型不因本项目采用 MIT 而自动获得新的授权。

## 常见问题

| 现象 | 检查方式 |
| --- | --- |
| 启动后离线 | 确认后端已运行；公开包默认连接本机 8787，不会连接原团队内网。检查 `http://127.0.0.1:8787/api/v1/health` 和“工具与日志”中的 API 地址。 |
| 网页正常、客户端异常 | 比对两者实际 API 地址和版本，导出脱敏日志；不要反复清缓存。其他服务器地址可在构建时用 `SPEAKER_API_BASE` 指定。 |
| Model not exist | 检查账号/地域可用模型、后端模型目录及业务空间，不能单凭报错认定客户端版本太旧。 |
| 音色配额已满 | 厂商配额与本地条目不是一回事；查询并删除无用云端音色，检查删除队列与后端清理结果。 |
| 本机识别不可用 | 检查 macOS 26、设备/语言支持、系统资源与离线工作程序架构。当前公开测试包的离线核心为 arm64。 |
| 任务失败/超时 | 先看具体任务错误、时长、大小和后台状态。任务失败不必然表示整台服务器离线。 |
